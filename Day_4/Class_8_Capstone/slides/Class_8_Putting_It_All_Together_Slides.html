def search_policy(query, top=3):
    q = embed(query)
    ranked = sorted(store,
        key=lambda s: cosine(q, s[1]),
        reverse=True)[:top]
    return [{"id": c["id"], "text": c["text"]}
            for c, v in ranked]

Worksheet: reading a ❌

🔧

Wrong tool

The agent chose a tool that cannot answer. Fix: the tool descriptions.

🔎

Wrong clause

Retrieval did not return the right id. Fix: chunking or the embedding model.

👀

Ignored the result

The right facts were there. Fix: the rules, or a stronger model.

The printed tools tell you where to look.
