Key terms: the loop

Term 13Notebook · Cell 5
Think–Act–Observe loop

Think: decide the next step. Act: request a tool. Observe: read the result. Repeat until the goal is reached. (Also called ReAct.)

In your worldCheck, read the result, decide the next check.
Term 14Notebook · Cell 5
Observation

The result a tool returns to the agent. It becomes the next input to think about.

In your worldThe answer in SE16.
Term 15Notebook · Cell 7
Step limit

A maximum number of passes through the loop, so an agent cannot run forever.

In your worldA timeout on a background job.
Term 16Notebook · Cell 5
Trace

The printed record of every think, act and observe line. It lets you check the agent's work.

In your worldA debugger log.

Key termThink–Act–Observe loop

Cell 5: the whole loop fits on one screen

for step in range(1, max_steps + 1):
    reply = chat_json(messages)              # THINK
    if "answer" in reply:
        return reply["answer"]               # FINISH
    result = execute(reply)                  # ACT
    messages += [                            # OBSERVE
      {"role": "assistant", "content": reply},
      {"role": "user", "content": "Tool result: " + result}]
# step limit reached → stop

Read it in four lines

Think: the model replies with a tool request or an answer.
Act: the program runs the tool.
Observe: the result is added to the conversation.
Repeat until it can answer, or the step limit hits.

Which SAP tasks suit an agent?

✅

Good fit

Multi-step investigations where the next step depends on what you find.

📋

Good examples

PO follow-ups · IDoc error investigation · invoice exceptions · month-end checks

⚠️
