Cell 6: store the fingerprints

fingerprints = embed([c["text"] for c in chunks])
store = list(zip(chunks, fingerprints))

a, b, c_ = embed([
  "Who approves a big purchase order?",
  "Director approval is needed above ₹10 lakh",
  "Payment runs happen on Tuesday and Friday"])
print(cosine(a, b), cosine(a, c_))
What you will see
Stored 22 chunks. Each fingerprint is a list of N numbers.

big PO question ↔ Tuesday payment run: lower

N depends on the embedding model · the first score should be clearly higher than the second

Key termTop-k retrieval

Cell 7: find

def find(question, top=3):
    q = embed(question)
    ranked = sorted(store,
        key=lambda s: cosine(q, s[1]),
        reverse=True)[:top]
    return ranked
