NOVA INDUSTRIES · IDOC ERROR HANDBOOK (MOCK, FOR TRAINING ONLY)
Version 1.4 · Effective 01 March 2026 · Owner: SAP Integration Team

1. COMMON STATUS CODES
1.1 Status 51 means the IDoc reached SAP but the application document was not posted. Typical causes are missing master data (for example a vendor or material that does not exist), a closed posting period, or a wrong plant.

1.2 Status 56 means the IDoc has errors added. This is usually a missing or wrong partner profile. Check the partner profile (WE20) and the message type.

1.3 Status 02 means there was an error passing data to the port. Check the port definition (WE21) and the connection.

1.4 Status 64 means the IDoc is ready to be passed to the application. It is normally picked up by the background job RBDAPP01. If many IDocs are stuck at 64, check that this job is scheduled and running.

1.5 Status 53 means the application document was posted. This is the success status and needs no action.

2. FINDING AND FIXING
2.1 Display an IDoc and its error message in WE02. Use the status monitor BD87 to select IDocs by status.

2.2 After the cause is fixed, reprocess the failed IDocs in BD87. Do not reprocess before the cause is fixed, because the IDoc will fail again.

2.3 Escalate to the Basis team when the error points to the port, the RFC connection or the network.
